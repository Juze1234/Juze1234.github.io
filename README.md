# Sergey Senchenko — Game Development Portfolio

Bilingual technical design portfolio focused on gameplay scripting, multiplayer systems, level design, and hands-on QA.

## Featured project

**Metro W.A.R. RP** is an independent multiplayer survival and roleplay project built on DayZ. The portfolio documents personal contributions to Enforce Script gameplay systems, model integration, level design, progression and economy, and multiplayer testing.

## Portfolio

The public site is deployed through GitHub Pages. English and Russian versions are available through the language switch in the header.

## Local development

```bash
npm install
npm run dev
```

## Production builds

```bash
npm run build
npm run build:pages
```
